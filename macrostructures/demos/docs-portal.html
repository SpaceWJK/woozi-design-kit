웹훅 서명 검증

리플로는 모든 웹훅 페이로드에 Reflow-Signature 헤더를 함께 보냅니다. 이 문서는 헤더 구조와, 서버에서 서명을 검증해 위조된 요청을 걸러내는 방법을 다룹니다.

중요 — 서명 검증 없이 웹훅을 처리하면 누구나 엔드포인트에 임의 페이로드를 전송할 수 있습니다. 프로덕션 환경에서는 반드시 검증 단계를 거치세요.

서명 헤더 구조

Reflow-Signature 헤더는 타임스탬프와 HMAC-SHA256 서명을 콤마로 이어 붙인 문자열입니다. 서명 원문은 {timestamp}.{payload}를 웹훅 시크릿으로 해시한 값입니다.

# 헤더 예시
Reflow-Signature: t=1755123456,v1=8f3a1c9e2b7d4f0a6c1e9b2d7a4f8c3e1b9d2a7f4c8e1b3d9a2f7c4e8b1d3a9f

curl로 빠르게 검증하기

테스트 목적이라면 아래처럼 수신한 헤더와 원문 페이로드를 그대로 재계산해 비교할 수 있습니다.

# 로컬에서 서명 재계산
echo -n "1755123456.{\"event\":\"payment.completed\"}" \
  | openssl dgst -sha256 -hmac "$REFLOW_WEBHOOK_SECRET"

Node.js로 검증하기

실제 서버 코드에서는 아래 미들웨어 패턴을 권장합니다. 타임스탬프가 5분 이상 벗어나면 재전송 공격으로 간주해 거부합니다.

// verifyWebhook.js
const crypto = require('crypto');

function verifyReflowSignature(header, rawBody, secret) {
  const [tsPart, sigPart] = header.split(',');
  const timestamp = tsPart.split('=')[1];
  const signature = sigPart.split('=')[1];

  const expected = crypto.createHmac('sha256', secret)
    .update(`${timestamp}.${rawBody}`)
    .digest('hex');

  const age = Date.now()/1000 - Number(timestamp);
  if (age > 300) throw new Error('signature expired');
  return crypto.timingSafeEqual(Buffer.from(signature), Buffer.from(expected));
}

재시도 정책

엔드포인트가 2xx 이외의 응답을 반환하면 리플로는 지수 백오프로 최대 6회까지 재전송합니다.

실패 응답재시도 간격최대 횟수
타임아웃 (5s 초과)30초 → 2분 → 10분6회
5xx1분 → 5분 → 30분6회
4xx (서명 오류 제외)즉시 중단0회
